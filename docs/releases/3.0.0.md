# Conceptmod 3.0.0

Model-independent concept editing, packaged with the same core/product boundary
as particle-sliders-core. Pretrained models live in seven separate HyperGAN
repositories; model-format converters are a separate package.

```sh
python -m pip install https://github.com/HyperGAN/conceptmod/releases/download/v3.0.0/conceptmod-3.0.0-py3-none-any.whl
conceptmod validate --phrase 'red=blue'
```

The release contains a wheel, source distribution and SHA-256 checksums.

- Immutable edit plans validate before model loading.
- Explicit model views and sessions own reference behavior, accumulation,
  optimizer/RNG state and exact continuation.
- Complete inference bundles include every edited component and remain distinct
  from training checkpoints. All weights are raw; weight EMA is disabled.
- The wheel and strict editable installs expose 19 reviewed runtime modules.
  Research, test fixtures, native model loaders and converters are excluded.

Conceptmod keeps its editing DSL/API and tested ParticleGAN 0.9.4 dependency.
It follows particle-sliders' ownership and packaging template without claiming
interchangeable numerical APIs or changing a training cohort.

Validation: 532 source tests passed with two previously documented research
expected failures; 121 installed-core tests passed outside the checkout. All
eight product suites passed 153 tests with seven explicit optional skips,
including exact model and encoder checkpoint continuation. Wheel, strict
editable, source-rebuild and package metadata checks passed. CPU fixtures do not
qualify pretrained model quality.
