# Conceptmod 3.1.2

Installing Conceptmod now pulls ParticleGAN 0.11.0 from PyPI. Fresh
particle-LoRA trainers explicitly select the upstream EMPF preset. Initial
learning rates are 0.012 for the generator, 0.018 for the critic and 0.03
for the particle bank. The regularizer runs on every update (`lazy_k=1`).
Training and inference use raw weights with weight EMA disabled.
[ParticleGAN 0.11.0](https://pypi.org/project/particlegan/0.11.0/) ·
[Full EMPF settings](https://github.com/HyperGAN/conceptmod/blob/v3.1.2/docs/particle-lora.md).

```sh
python -m pip install https://github.com/HyperGAN/conceptmod/releases/download/v3.1.2/conceptmod-3.1.2-py3-none-any.whl
```

**Highly experimental and untested on real models.** GPU resources for
end-to-end training and evaluation are unavailable. The CPU tests cover
recipe matching, regularizer execution and checkpoint replay. Real-model
training stability and concept-editing quality remain unverified.
