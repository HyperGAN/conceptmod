# Conceptmod 3.1.0

Updates ParticleGAN from 0.9.4 to the published 0.10.0 release. Fresh
`ParticleLoRAGenerator.make_trainer` calls use its official `rhbi_optimized`
default, including RHBI, SBNP and DualNorm. Loss, regularizer, optimizer and
numerical-profile implementations remain upstream.

The dependency uses upstream's immutable release-source commit `952c3b62` because
the 0.10.0 PyPI publication failed. Installation builds that release from its
public GitHub archive; the archive is large because it includes research output.

```sh
python -m pip install https://github.com/HyperGAN/conceptmod/releases/download/v3.1.0/conceptmod-3.1.0-py3-none-any.whl
conceptmod validate --phrase 'red=blue'
```

The trainer factory accepts an explicit upstream `Recipe`. For restoration,
use `Recipe.from_dict(checkpoint["recipe"])` before loading the full state.
The saved recipe owns dimensions and budget; resolving the new default for an
existing run is not a migration. Explicit BISPF, EMPF and RHBI recipes are
supported. Upstream validation still rejects incompatible checkpoints, which
must use their original pinned runtime.

Weight EMA and served averaging stay disabled. Recipes enabling either, or a
legacy critic EMA anchor, are rejected. Frozen host weights, zero-output LoRA
initialization and historical research formulations are preserved. Existing
checkpoints, learning-rate measurements and native training runs are untouched.

The package retains 19 reviewed core modules and the strict editable boundary.
The model-independent DSL and separate product APIs remain unchanged. Small CPU
fixtures verify integration and exact next-step state restoration; they do not
qualify pretrained-model quality or establish a new best learning rate.

Validation: **539 passed, 2 existing research xfailed** in the clean Python 3.11 /
Torch 2.14.1 CPU source suite; **128 passed** against the installed wheel outside
the checkout. RHBI, BISPF and EMPF each restore the complete next-step model,
optimizer, formulation-record and RNG state exactly. Wheel/source builds,
metadata validation, strict editable imports and installed-core checks pass.
Every file body in the dependency wheel built from the pinned public archive
matches the upstream release's tested CI wheel. No pretrained model or GPU
training run was started for this update.
